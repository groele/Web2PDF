# Web2PDF v4.0.0

Release date: 2026-09-14.

## Overview

Publish the redesigned export workspace, capture responsiveness improvements, scroll-lock fixes and popup expansion repair.

The popup now requests a stable 600px content height. Removing its viewport-height cap avoids a circular sizing dependency in extension popups. Advanced settings scroll within the settings panel; smaller browser viewports can scroll the document to reach export actions.

Capture scroll is locked synchronously before the first asynchronous yield. Wheel and navigation-key events cannot reach page handlers during capture. The progress dialog's Space-key cancel action remains available.

## Compatibility and migration

No intentional breaking API, storage or configuration change. Existing saved preferences remain valid. Refresh already-open pages after updating so their content script matches version 4.0.0. The major version number follows the user's requested V4.0 release.

PDF files remain image-based documents. Cross-origin assets, complex page layouts and authenticated WOS pages still require page-specific checks. Cancellation is cooperative; an active renderer call must settle before cleanup completes.

## Validation

- JavaScript syntax checks passed for popup.js and content.js.
- Popup browser regression passed 18/18 checks with mocked extension APIs, covering preferences, reconnect, version handshake, advanced settings and constrained viewport scrolling.
- Export browser regression passed 32/32 checks using the bundled html2canvas/jsPDF libraries with a mocked extension message boundary; real PDF/PNG/JPEG bytes, scroll lock, cancellation, cleanup and retry were verified.
- Chromium layout inspection at 400x600 confirmed advanced controls remain above the export dock after scrolling and no horizontal overflow occurs.
- Historical rendering/performance evidence is retained in tests/v3.6-validation.md and is not a new v4.0.0 benchmark.

These tests do not prove native extension popup sizing or authenticated WOS fidelity.

## Install

Extract the extension archive, open Chrome or Edge's extensions page, enable Developer mode and choose Load unpacked. Select the directory containing manifest.json. Reload an existing installation and refresh target pages.

For rollback, retain the previous extension directory and reload it as unpacked; no storage migration is performed by this release.
