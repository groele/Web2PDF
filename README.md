# 网页区域 PDF 导出器

当前版本：**v3.4.0**。Chrome / Edge 扩展，使用内置 html2canvas 与 jsPDF 在本地生成 PDF、PNG 或 JPEG。

## 使用流程

1. 点击“自动识别主体”，或“选择页面区块”后单击目标。手动选择前可用 ↑ 扩大到父容器。
2. 拖动上、下蓝色手柄裁切。调整限定在初始元素范围内，扩大初始范围请重选父容器。
3. 手柄可用 Tab 聚焦，再按 ↑/↓ 微调 1 像素，Shift + ↑/↓ 微调 10 像素。
4. 点击“导出此区域”下载；“重选”重新定位，Esc 或取消按钮退出。

支持 2× / 3× / 4× 渲染、文件名设置、A4 分页及单页自适应尺寸。过长页面会降低倍率；自适应 PDF 超出单页尺寸上限时改用 A4 分页。

## 限制

- 自动识别使用页面结构启发式，需人工确认范围。
- PDF 是网页渲染结果的位图，不是可检索的矢量文字。
- 跨域图片、iframe、复杂 CSS 和内部滚动容器可能无法完整重现。
- 当前先渲染完整元素再裁切，极长元素即使只保留一小段也可能触及内存限制。
- 页面尺寸在调整期间改变时，请重新选择。仅裁切上下范围，暂不支持任意扩展或左右裁切。

## 安装与更新

下载项目并解压。在 Chrome 或 Edge 扩展管理页开启“开发者模式”，选择“加载已解压的扩展程序”并选中项目文件夹。

更新后在扩展管理页点击“重新加载”，再刷新待导出的网页。
