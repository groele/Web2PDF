# 网页区域 PDF 导出器 (Chrome / Edge 浏览器扩展)

一款面向**学术论文、科研文献与各类网页内容**的高保真 PDF 直接下载插件。

---

## ✨ 为什么重命名为「网页区域 PDF 导出器」？

此前插件名称带有特定学术数据库名称，局限性过大。现以“导出网页区域”作为清晰的核心能力，学术文献是重点适配场景：
- **全网学术平台通用**：全面支持 Web of Science、PubMed、IEEE Xplore、知网 (CNKI)、Nature、Science、Springer、ScienceDirect、arXiv 等各类学术数据库；
- **全网常规网页通用**：技术博客、新闻资讯、文档教程等任意网页均可一键高保真提取导出；
- **纯客户端直出**：采用内置离线引擎（`html2canvas` + `jsPDF`），直接将已渲染的网页区域写入 PDF，完全绕过浏览器的 `window.print()` 打印弹窗。

---

## ⚡ 核心功能与亮点

1. **⚡ 自动识别主体**：为文献详情和文章页推荐核心内容区；如识别不符合预期，可立即改用自选区域。
2. **🎯 自选页面区块**：鼠标点选一个网页元素后直接导出；适合图、表、卡片或任意局部内容。
3. **📐 自适应渲染倍率**：支持 `2× / 3× / 4×`；内容过长时会自动降低倍率以避免浏览器内存耗尽。
4. **💎 无损 PNG 选项**：普通长度内容可使用 PNG 保留细小文字；超长内容会自动改用高质量 JPEG，以保持可用的文件体积与生成成功率。
5. **📄 安全分页**：A4 模式优先在段落、表格、图片等内容块边界分页；长图超过常见 PDF 阅读器的安全高度时会自动改为 A4 分页。

> PDF 由网页渲染结果生成，内容为高分辨率位图而非可检索的矢量文字。实际清晰度与网页原始 CSS 尺寸、所选渲染倍率和页面长度共同有关。

## 使用提示

- 选择“自动识别主体”后，插件会高亮推荐区域；确认范围正确后再点击“导出此区域”。
- 选择页面区块时，鼠标悬停到目标内容后可按 <kbd>↑</kbd> 逐级扩大至父容器，再单击导出；<kbd>Esc</kbd> 取消。
- 若页面过长，插件会优先降低倍率、改用高质量 JPEG 或回退至 A4 分页。无法在清晰度阈值内安全导出的超长选区，应分段导出。
- 跨域图片未允许 CORS 时，浏览器安全机制可能使该图片无法进入 PDF；请使用原网站提供的下载内容，或选择不包含该嵌入资源的区域。

## 隐私与权限

导出在本地浏览器完成，不上传网页内容或 PDF。Web of Science/Clarivate 采用预声明页面权限以显示工具条；其他站点仅在你点击扩展图标后临时访问当前标签页。详见 [PRIVACY.md](PRIVACY.md)。

## 🚀 重新加载生效步骤（10 秒）

### 如果您之前已在浏览器加载了插件：
1. 打开浏览器的扩展管理页：
   - **Chrome**：在地址栏输入 `chrome://extensions/` 回车。
   - **Edge**：在地址栏输入 `edge://extensions/` 回车。
2. 找到本插件卡片（名称为 **「网页区域 PDF 导出器」**，版本号 **v2.4.0**）。
3. 点击卡片右下角的 **「重新加载 ⟳」** 按钮。
4. 回到网页按键盘 <kbd>F5</kbd> 刷新即可使用！

### 首次安装步骤：
1. 打开浏览器扩展管理页面，开启右上角的 **「开发者模式」**。
2. 点击 **「加载已解压的扩展程序」**，直接选中目录：
   ```text
   D:\New doc
   ```
3. 点击「选择文件夹」即可完成安装。
