# 网页区域 PDF 导出器

当前版本：**v3.6.0**。Chrome / Edge 扩展，使用内置 html2canvas 与 jsPDF 在本地生成 PDF、PNG 或 JPEG。

## 使用流程

弹窗提供格式、速度与清晰度预设、页面规格和文件名；自定义倍率、四边留白和 PDF 无损选项位于高级设置。设置区可滚动，底部操作按钮保持可见。图片模式自动隐藏 PDF 专属设置，留白输入框显示对应默认值。网页中的操作面板跟随选区，并保持在屏幕内；小屏支持换行。

1. 点击“识别正文”，或“手动选区”后单击目标。手动选择前可用 ↑ 扩大到父容器。
2. 普通页面使用“页面矩形”：显示宽 × 高（网页 px，不含留白），可输入尺寸、拖动四边/四角或拖动框体平移。选区可跨越初始元素扩展；拖到屏幕边缘自动滚动。“原始尺寸”恢复最初范围。
3. 检测到独立滚动侧栏时，默认选择“完整滚动区域”：包含容器标题和内部正文，在副本中展开纵向内容，保持原宽度。界面高度明确标为估算；需要手动裁剪时切换“页面矩形”。
4. 方向键平移选区；Tab 聚焦手柄后，方向键微调该边缘。Shift 将步长从 1 px 改为 10 px。输入框内 Enter 仅应用尺寸，不直接导出。
5. 点击“导出文件”下载；失败会保留选区供重试。导出中暂时锁定滚动；结束后恢复。“重选”重新定位，Esc 或取消按钮退出。

支持 1.5× / 2× / 3× / 4× 渲染、文件名设置、A4 分页及单页自适应尺寸。首次使用默认 2× 平衡预设；已有倍率偏好会保留。

- 快速：1.5×，PDF 内嵌 JPEG，适合日常分享。
- 平衡：2×，PDF 内嵌无损 PNG，适合清晰归档。
- 精细：3×，PDF 内嵌无损 PNG，适合放大查看。
- PNG 输出始终无损；JPEG 输出始终使用 JPEG。切换预设同时更新倍率和 PDF 编码设置。

导出面板显示准备、渲染、编码、下载四个阶段及实际耗时。进度条表示阶段，不是时间估计。取消按钮或 Esc 请求取消，当前渲染结束后停止后续步骤，保留选区供重试。html2canvas 内部渲染和 jsPDF 的单次编码/保存不能即时中断。

过长页面会降低倍率；自适应 PDF 超出单页尺寸上限时改用 A4 分页。

## 限制

四边留白可在弹窗中分别设置为 0–50 mm，并自动保存。留空沿用默认：A4 上下 12 mm、左右 10 mm；自适应 PDF 四边 6 mm；图片四边 0。PNG/JPEG 白边按 96 CSS 像素/英寸换算并随渲染倍率缩放。PDF 不添加页码。无损选项保持 PNG 编码，不自动改用 JPEG；实际倍率仍受画布内存和边长上限约束。

- 自动识别使用页面结构启发式，需人工确认范围。
- PDF 是网页渲染结果的位图，不是可检索的矢量文字。
- 跨域图片、iframe、Shadow DOM、复杂 CSS 可能无法完整重现；展开侧栏只涵盖已加载的 DOM，不会自动加载虚拟列表或尚未请求的数据。横向内容保持原始容器宽度，不承诺横向滚动拼接。
- 截图按页面坐标和选区尺寸创建画布，仍需解析页面结构；复杂页面仍可能耗时。
- 页面矩形固定在页面坐标；动态内容改变位置后请确认或重选。

## 回归验证

`tests/export-regression.js` 是用于已连接 Playwright 浏览器的回归函数，使用内置真实渲染器，模拟扩展消息接口。先在项目目录运行 `python -m http.server 8765 --bind 127.0.0.1`，再由浏览器工具执行该文件。测试不等同于真实登录 WOS 页面及已安装扩展的端到端验收。手动侧栏示例位于 `tests/scroll-sidebar.html`。`tests/popup-regression.js` 检查预设、存储、连接重试及紧凑视口。v3.6.0 验证与性能边界见 [验证记录](tests/v3.6-validation.md)。

## 安装与更新

下载项目并解压。在 Chrome 或 Edge 扩展管理页开启“开发者模式”，选择“加载已解压的扩展程序”并选中项目文件夹。

更新后在扩展管理页点击“重新加载”，再刷新待导出的网页。

如果弹窗提示页面仍在运行旧版脚本，必须刷新该网页。已有选区时再次点击扩展按钮会复用当前选区，不会重复创建截图窗口；导出进行中不能启动第二个选区。
